About

Learning fast, shipping carefully

I started building for the web because I liked seeing an idea become something people can click. Since then I've focused on React and clean, responsive layouts.

I'm a junior software engineer based in Lahore, Pakistan. Most of my work so far has been front-end: translating designs into React components, wiring them to APIs, and making sure everything holds up on small screens. I care about readable code, honest naming and interfaces that don't fight the person using them.

Day to day I'm strongest in React, JavaScript, HTML, CSS and Tailwind, with Git for version control. I'm still early in my career, so I ask questions, take review feedback seriously, and try to leave each project a little tidier than I found it.
